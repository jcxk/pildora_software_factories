Teaching package for a 45-min Spanish session: **«Tenemos que ir más profundo» — Docker Compose y microservicios** — built **entirely local** in this repo (no push, no GitHub, no Pages until you explicitly say so).

**Theme:** the talk IS Inception. Open with the meme + the movie analogy (dreams within dreams = going deeper technically). Descend through the dream levels — **Nivel 1 (fácil)**: Docker recap, one container · **Nivel 2 (medio)**: microservices with Docker Compose, the heart · **Nivel 3 (avanzado)**: growing up — healthchecks, scaling, prod concerns, when Compose falls short (K8s teaser) · **Limbo**: the too-deep warning (microservices por moda, K8s para todo, sobre-ingeniería). Then back up for the in-class práctica (Nivel 2 hands-on) and the closing kick.

**Timing (45'):** 3' gancho+analogía · 5' Nivel 1 · 9' Nivel 2 · 4' Nivel 3 · 2' Limbo · 20' práctica · 2' cierre.

## 2 · Demo app — `demo/` «niveles de sueño»
`web` (nginx + JS) → `api` (FastAPI `/nivel`, cache hit/miss) → `cache` (Redis) → `db` (MySQL 8 + seed). `compose.yml` with custom network, named volume, healthchecks, `depends_on: service_healthy`, `.env`. The app's "nivel de sueño" counter mirrors the talk's levels. Spanish comments, small files, `prepull.sh` to pre-fetch images. Validated with `docker compose config` (+ up→curl→down if Docker runs).

## 3 · Práctica — `practica/` (~20' in class, Compose taught hands-on)
Step cards pairing each step with its compose concept: **P0** verificar Docker + cómo clonar (QR/URL placeholder until the repo goes public) · **P1** `docker compose up` + observar → services / un archivo, un comando · **P2** `logs`, `exec`, DNS → redes y DNS por nombre · **P3** añadir Adminer → anatomía YAML de un servicio · **P4 bonus** persistencia + escalar → volúmenes, healthchecks (stretch/homework). Cards: objetivo, comandos, resultado esperado, «qué acaba de pasar».
